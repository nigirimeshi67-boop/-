## 問題がランダムじゃない
これはそうだよ(便乗)
ミスった問題は次回からの排出率が高くなります
具体的には
ミスる
→ミスった問題リスト(以降ミスリスト)に追加
次の問題に行く
→元の問題からかミスリストからか2分の1で排出
というシステムになってます
なので1問ミスったらその問題は大体50％で排出されます
